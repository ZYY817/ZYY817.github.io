校验你下载的文件Verify what you downloaded

哈希值就像文件的数字指纹——哪怕在传输或转存时被改动了一个字节，算出来的结果也会天差地别。下载完成后，可以在文件所在目录打开 PowerShell 或命令提示符跑一行命令（如果下的是便携版或 v0.1.2，把命令里的文件名换成你实际下载的文件名即可）：A SHA‑256 hash is a file's digital fingerprint — even a single altered byte changes it completely. After downloading, run either command below in the folder where the file is saved (replace the filename if you downloaded the portable ZIP or v0.1.2):

# 方式 1：Windows PowerShell 原生命令（推荐，以 v0.1.4-preview 安装版为例）# Method 1: Windows PowerShell (recommended, shown for v0.1.4-preview installer)
Get-FileHash .\YuqiEngine-v0.1.4-preview-win-x64-setup.exe -Algorithm SHA256 | Format-List
# 方式 2：经典 CMD / certutil 命令# Method 2: CMD / certutil
certutil -hashfile YuqiEngine-v0.1.4-preview-win-x64-setup.exe SHA256

将算出的哈希串与 GitHub Releases 发布页 上的校验说明或 .sha256 文件核对，完全一致再运行。哪怕从网盘镜像下载，也能用这行命令确认文件原封未动。Compare the output against the checksum notes or .sha256 file on GitHub Releases. This lets you confirm any download — including from the mirror — is untouched before running it.

03

关于安全提示About security warnings

“未知发布者”“Unknown publisher”

宇奇引擎由作者个人独立开发，尚未购买昂贵的企业级 EV 代码签名证书，Windows SmartScreen 可能提示“未知发布者”。这属于证书签名机制，不代表包含病毒；只要哈希校验一致，点击“更多信息 → 仍要运行”即可。Yuqi Engine is independently developed and has no expensive corporate EV certificate, so SmartScreen may warn of an “unknown publisher”. That's a signature matter, not malware — click “More info → Run anyway” once verified.

管理员权限Administrator rights

只读检测完全不需要管理员权限。只有在你主动勾选并点击应用系统修改时，软件才会明确提示提权——修改系统底层服务与注册表本来就需要系统管理员身份。Read-only inspection needs no admin rights. Only when you apply system tweaks will the app ask for elevation — that's expected since modifying system services and the registry requires it.

杀毒软件报警Antivirus alerts

修改系统服务、注册表键值和电源计划的工具，容易被安全软件的启发式扫描判定为风险。宇奇引擎源码已在 GitHub 公开可审查；仍有疑虑，可以完全只用检测功能，不应用任何写入。Tools touching services, the registry and power plans often trigger heuristic alarms. The source code is public on GitHub; if in doubt, you can strictly inspect without applying any changes.
