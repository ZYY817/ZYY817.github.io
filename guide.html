01

使用前，四步原则Before you start: four principles

01. 创建系统还原点01. Create a restore point

软件内置「系统还原点」工具，先建一个。这是修改失败时最直接的退路。Use the built-in “System Restore Point” tool first. It's the most direct way back if something goes wrong.

02. 备份重要个人文件02. Back up personal files

还原点保护的是底层系统设置，不包含个人文档、照片与存档。重要数据请自行备份到移动硬盘或网盘。A restore point covers Windows system settings, not personal files or saves. Back those up separately.

03. 首次启动只看不点03. Inspect before applying

首次打开先完整运行一次检测。只做检测绝不改动任何设置，先看清每一项的真实状态。Run inspection first. It touches nothing — see the current state of each item and what the app reports.

04. 只勾选你看得懂的项04. Only check what you understand

每一项都写明作用、风险与恢复方式。拿不准、看不懂的项先不动，查清楚再决定。Every item spells out purpose, risk and undo path. Leave anything unclear unchecked until verified.

02

读懂状态标签Reading the status labels

状态不是评分，它只是当前信息的完整程度。宇奇引擎从不给电脑打 90 分或 60 分，只客观陈述每一项是知道、不知道、还是不能动。 Status isn't a score — it's how complete the information is right now. Yuqi Engine never grades your PC with arbitrary scores, but truthfully reports whether each item is known, unknown, or locked.

出问题了？带上证据反馈Something wrong? Report it with evidence

问题包会收集A diagnostics package includes

  • 系统版本与基础硬件信息OS version and hardware specifications
  • 相关模块的检测与操作日志Inspection and execution logs of related modules
  • 各项设置的最终复核状态Final verification results for each setting

问题包不包含It does not include

  • 个人文件、文档、照片、浏览器数据Personal files, documents, photos, browsing data
  • 账号密码与凭据信息Passwords, credentials or tokens
  • 未经脱敏的原始用户名、计算机名与具体路径（生成时已在本地自动隐去）Raw unmasked usernames, machine names or file paths (masked locally before saving)

问题包在本地生成纯文本压缩包，绝不私自联网上传任何数据。你可以在本地解压审查每一行内容后，连同「做了什么操作、期望什么结果、实际发生了什么」一起发到 GitHub Issues。信息越具体，越容易排查。The diagnostic package is generated locally as a plain text ZIP and never uploaded without your consent. Inspect every line if you wish, then submit it to GitHub Issues with details on what happened.

04

常见问题FAQ

用了之后帧数能提升多少？真能让游戏变快吗？How much FPS will I gain? Will it make games faster?
宇奇引擎绝不承诺具体的帧数或延迟提升——不同硬件、显卡驱动、系统版本的差异极大，任何承诺“提升 60% FPS”的固定数字都是虚假营销。宇奇引擎做的是关闭不需要的后台服务与轮询，减少游戏调度时的偶发性卡顿与掉帧（改善 1% Low 帧）。如果系统瓶颈在显卡或 CPU 物理性能，软件无法突破物理规律。Yuqi Engine makes no fixed FPS or latency promises — hardware, drivers and OS builds vary too much for any honest number. What it does: disable unneeded components, tune background polling, and reduce frame jitter (improving 1% Low FPS). If your bottleneck is hardware capability, no software can break the laws of physics.
为什么不做“一键推荐全部优化”？Why isn't there a "One-Click Optimize All" button?
每个人的电脑使用环境完全不同——有的用户需要打印机，有的需要 Xbox 联机服务，有的要跑开发虚拟机。“一键优化”本质上是把别人的配置盲目强加给你的电脑，往往是系统崩溃或功能缺失的根源。我们坚持“先看懂，再选择”，不替你做擅自主张的黑盒决定。Every computer setup is unique: some need printing, some need Xbox networking, some run virtualization. “One-click optimize” forcibly imposes someone else's preferences onto your system, often leading to crashes or broken features. We insist on “understand first, then choose.”
改坏了能恢复吗？Can I undo a bad change?
大部分修改可以在软件内恢复，恢复前会再次读取当前真实状态。此外强烈建议在使用前创建系统还原点，实现双重保险。这也是为什么我们一直强调「在动手之前，先留好退路」。Most changes can be reverted inside the app — it re-reads the current state before restoring. Still, creating a system restore point beforehand is strongly recommended. That's why we keep saying: set a fallback first.
为什么有些项目显示「待确认」或「不可用」？Why do some items show “Pending” or “Unavailable”?
这正是宇奇引擎与黑盒工具的区别——“软件知道自己不知道什么”。如果底层接口未返回明确状态、复核不通过或系统版本/硬件不支持，软件绝不虚报成功，而是如实标出并保持安全锁定。另外，如果你的系统装的是精简版镜像、或已经被深度调校工具改过，很多接口本身就被移除了，大片「不可用」是正常现象——这种状态不适合再批量改动，逐项看清说明再动。This is what sets Yuqi Engine apart: the software knows what it doesn't know. If low-level APIs return uncertain data or hardware lacks support, it never fakes success — it reports honestly and keeps the setting safely locked. One more case: on systems installed from debloated images or already heavily tuned, whole interfaces have simply been removed — a wall of “Unavailable” is normal there. Don't bulk-apply on those systems; read each item before touching it.
Windows 提示「未知发布者」，杀毒软件报警怎么办？Windows says “unknown publisher” or antivirus warns — what to do?
软件由个人独立开发，尚未购买昂贵的商业代码签名证书，且修改系统服务与注册表的工具容易触发杀毒软件的启发式误报。确保你是从本网站官方渠道或 GitHub Releases 下载，并比对 SHA‑256 校验值；若仍有顾虑，可以完全只用检测功能，不应用任何写入。The app has no expensive corporate signing certificate, and touching low-level services triggers heuristic antivirus alarms. Verify the SHA‑256 hash against official GitHub Releases; if in doubt, you can strictly inspect your system without applying any changes.
v0.1.2 和 v0.1.4-preview 选哪个？v0.1.2 or v0.1.4-preview?
日常检测推荐 v0.1.4-preview：体积轻、内置运行库，普通权限即可看清系统现状。v0.1.2 是完整工程丢失前的最后一个版本，功能更全面，但官方建议具备系统还原经验的用户体验。两个版本的详细差异见下载页。For everyday inspection, pick v0.1.4-preview: lighter download, runtime bundled, works without elevation. v0.1.2 is the last build before the full project was lost — more complete, but officially recommended only for experienced users.
