项目故事Story

一个人，
在下班后慢慢磨出来的。Built by one person,
in the hours after work.

宇奇引擎是智宇借着 AI 的手一点点做出来的作品——代码、界面与文档初稿大多出自 AI；但要做什么、砍掉什么，在一台台真机上反复跑测、把不对劲的地方推倒重来，每一个决定与最终兜底，背后都是一个具体的人。Yuqi Engine grew in Zhiyu's evenings with AI doing much of the drafting — code, interface and docs alike. Yet deciding what to build and what to cut, testing on real hardware, catching what felt wrong and standing behind every release — all of that is human work.

01

到现在，经历了这些The story so far

2026-02-27

首个内测版 v0.1-alpha 发布First alpha: v0.1-alpha

第一个对外公开的版本，在作者的哔哩哔哩和抖音频道发布。当时还只是一个把散落设置集中起来的自用工具。The first public build, released on the author's Bilibili and Douyin channels — then still a personal tool gathering scattered settings into one place.

2026-08-09

v0.1.2 发布：功能最完整的一版v0.1.2: the most complete build

中英文双语的完整体验版在 GitHub 发布，功能迭代到最完整的状态，也在玩家社区里积累起第一批用户。The bilingual, feature-complete release went up on GitHub — the fullest the project had ever been, gathering its first users in gaming communities.

2026 年 8 月August 2026

误删事故：最完整的工程没了The accident: the fullest codebase lost

一次误操作，让迭代到最完整的整套工程源文件没能留下，也没有可恢复的完整备份。这次事故成了最深刻的教训：本地保存不等于真正备份。这也直接塑造了宇奇引擎如今的核心底线——先建还原点、可逆可恢复、先留退路。One accidental deletion wiped the entire project at its most complete state — with no full backup to restore from. That accident became the hardest lesson: local storage is not a backup. It directly forged Yuqi Engine's core baseline: create restore points first, ensure full reversibility, and always have a way back.

2026-08-28

幸存的源码，整理后公开What survived, published

作者没有就此停掉项目。把幸存的部分整理成公开快照传到 GitHub，如实标注包含与不包含的内容——公开的目的之一，就是交给愿意继续完善它的人。Rather than abandoning it, the author organized what survived into a public snapshot on GitHub, documenting honestly what is and isn't there — partly to hand it to anyone willing to carry it forward.

2026-09-15

v0.1.4-preview：在幸存者上继续v0.1.4-preview: building on the survivor

在那份幸存的早期源码基础上继续打磨并发布：修复了管理员权限误提示与安全检测页报错，重做了 CPU 核心管理页。断掉的路，重新接上了。Development continued on that surviving early source: fixed the false admin prompt and the security check page crash, and rebuilt the CPU core management view. The broken thread was picked back up.

“先理解，再选择；可验证，也可恢复。”“Understand first, then choose. Verifiable, and reversible.”

宇奇引擎的核心底线——不做黑盒优化。也是那次事故之后，作者对每个用户最想说的一句话：在动手之前，先留好退路。Yuqi Engine's core baseline: no black-box optimization. And after that accident, the one message the author wants every user to take away: always set a fallback before you tweak.
